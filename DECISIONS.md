# Architectural and Implementation Decisions

- Pinned `antd` to `5.29.3` and `react` to `18.3.1` because `@refinedev/antd@6.0.3` declares `peerDependencies.antd: "^5.23.0"` and is not peer-compatible with `antd@6.x`.
- Pinned `typescript` to `5.9.3` to satisfy `typescript-eslint@8.72.1` peer bounds (`<6.1.0`) under strict typechecking.
- Injected CSS custom properties at startup from `src/theme/tokens.ts` so stylesheet rules also avoid hardcoded color values outside `tokens.ts`.
- Added `updated_at` to `projects` maintained automatically via triggers on `projects`, `categories`, `items` and `releases` to power the Projects list "Last updated" column accurately.
- Standardized canonical `manifest_hash` JSON objects with fixed alphabetical keys (`category_name`, `category_position`, `file_name`, `file_size`, `kind`, `sha256`, `title`, `url`, `version_label`) and `COLLATE "C"` / Unicode code-point sorting so PostgreSQL `publish_release` and TypeScript `computeManifestHash` produce identical SHA-256 digests.
- Enforced category "delete when empty" via `ON DELETE RESTRICT` on `items.category_id`, keeping archived items linked to their category for audit history.
- Treated archived projects as read-only for categories, items and releases until unarchived by a project owner, and prevented removing or demoting the last project owner via trigger.
- Used `@electric-sql/pglite` (`pgcrypto`) in Vitest to run the exact `supabase/migrations/` and `supabase/seed.sql` files against a real PostgreSQL engine during `npm run test` without requiring a running Docker daemon.
- Kept an item's `kind` (`file` or `link`) immutable after creation while allowing file items to upload replacement files to new `{project_id}/{uuid}/{file_name}` paths, and used direct `XMLHttpRequest` to the Supabase Storage REST endpoint so browser uploads report byte-level progress.
- Migrated the application shell and all screens to `@refinedev/antd` (`ThemedLayout`, `ThemedTitle`, `List`, `Create`, `Show`, `Edit`, `PageHeader`, `useTable`, `@refinedev/antd/dist/reset.css`) and removed Ant Design's legacy `wireframe` mode in favor of crisp 6px radii and subtle surface elevation.
- Standardized typography across all screens on `Inter` (`400`/`500`/`600`/`700`), a compact engineering Ant Design v5 scale (`13px` base, `18`/`15`/`14`/`13`/`12` headings, `30px` control height), CSS `text-box: trim-both cap alphabetic` optical alignment for icons/badges/avatars, relative `rem` stylesheet sizing with `<meta name="text-scale" content="scale" />`, and monospace (`revlog-hash`) strictly reserved for cryptographic SHA-256 and `manifest_hash` digests.
- Extracted sidebar navigation into a declarative, section- and submenu-capable configuration (`src/components/navigationConfig.tsx`) rendered inside a scrollable (`overscroll-behavior: contain; scrollbar-gutter: stable`) `RevLogSider` shell with an active-project switcher header and pinned collapse footer so future feature modules can be added cleanly.
- Expanded the data and UI hierarchy to three levels (`projects` → `products` (`'hardware' | 'software' | 'mixed'`) → `categories` (modules) → `items`) with shared project-level RBAC (`project_members`), safe automatic migration/backfill of single-product v1 projects, and dual-level immutable SHA-256 releases (`releases` per product plus `project_releases` + `project_release_products` bundling published product releases into a system baseline via `publish_project_release`).
- Adopted a Supabase Studio-inspired header-first navigation shell (`src/components/AppLayout.tsx`, `src/components/navigationConfig.tsx`): `/projects` and `/projects/new` render without a left sidebar as a clean project-selection card grid, a full-width top context bar (`RevLog / Project ⌄ / Product ⌄ / Section`) provides searchable project and product switcher popovers that preserve sub-routes, and the collapsible left sidebar renders only once a project is selected, scoping its menu items to the active project or active product.
- Stored BOM/PnP check runs (`public.bom_pnp_check_runs`) as append-only immutable JSONB snapshots attached to product releases (`releases`), enforced by PostgreSQL triggers and RLS so new runs can only be recorded on active draft releases and stored results remain permanently frozen once a release is published.
- Implemented deterministic KiCad, Altium and custom-mapped delimited CSV/POS parsing in plain TypeScript with automated column detection, code-point deterministic finding sorting, and interactive column mapping override support.
